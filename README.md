# Numerische Verfahren zur Datenanalyse – Projekt 6: Signalverarbeitung
Dieses Repository enthält numerische Implementierungen und Analysen zur Signalverarbeitung mit:
- **Fourier-Reihen** (z. B. Approximation von periodischen Funktionen wie der Hut-Funktion)
- **Diskreter Fouriertransformation (DFT)** & **Inverser DFT (IDFT)**
- **Schneller Fouriertransformation (FFT)** und Laufzeitvergleichen
